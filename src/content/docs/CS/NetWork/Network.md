## 网络分层

- 应用层：处理应用软件，位于整分层的最上层，此处分组信息称为`报文`
- 传输层：应用层信息由传输层传输，负责应用端点之间的传输，此层的分组称为`报文段`
- 网络层：包含 IP 协议和路由转发协议，但一般都称为 IP 层，负责将数据从一台主机传输到另一台主机，此层分组称为 `数据报`
- 链路层：负责链路节点之间的传输，分组在此处称为`帧`
- 物理层：物理层也是链路层，但是他除了描述节点之间的传输，还描述物理介质，如双绞铜线，光纤等

整个传输过程如下：

报文 => 报文段 => 数据报 => 帧 ... 帧 => 数据报 => 报文段 => 报文
