## dpkg

```shell
dpkg -s $packageName # 查看包的安装状态，包未安装则抛出错误
dpkg -l $packageName # 查看包的状态，部分电脑包未安装则抛出错误

```

## apt

```shell
apt list $packageName # 查看安装包的状态

apt-get download $packageName # 下载安装包到当前目录，可供其他人离线使用，但只能下载当前包，依赖包不会同时下载

# 查看源配置
cat /etc/apt/sources.list

# 查看 apt install 下载的包
/usr/bin 或者 /usr/sbin # 可执行文件一般安装在
/usr/lib 或者 /usr/lib64 # 库

# 下载的deb包缓存在
/var/cache/apt/archives
```
