# Cloud 概览

> 云计算 = 通过网络按需获取计算、存储、网络等资源。本目录收主流云服务商的服务、架构模式、成本优化。

## 知识地图

### 主流云服务商

- **AWS**（Amazon）—— 市场份额最大、服务最全
- **GCP**（Google）—— 大数据 / ML 强
- **Azure**（Microsoft）—— 企业市场强、与 Windows 生态集成
- **阿里云**（Alibaba）—— 国内主流
- **腾讯云 / 华为云** —— 国内第二梯队

### 计算服务

- EC2 / 虚拟机（VM）
- 容器服务（ECS / EKS / GKE / AKS）
- Serverless（Lambda / Cloud Functions / 阿里云 FC）
- 边缘计算（Cloudflare Workers / Vercel Edge）

### 存储服务

- 对象存储（S3 / OSS）—— 无限扩展
- 块存储（EBS / 云硬盘）
- 文件存储（EFS / NAS）
- 归档存储（Glacier / 冷归档）

### 网络

- VPC（虚拟私有云）
- 负载均衡（ALB / NLB / SLB）
- CDN（CloudFront / Cloudflare / 阿里云 CDN）
- API Gateway

### 数据库服务

- 托管关系型（RDS / Cloud SQL / PolarDB）
- 托管 NoSQL（DynamoDB / MongoDB Atlas / TableStore）
- 托管缓存（ElastiCache / MemoryDB）

### 架构模式

- 单体应用上云
- 微服务架构
- Serverless 架构
- 多区域 / 多活部署
- 灾备（DR）与 RPO / RTO

### 成本优化

- 按需 / 预留实例 / Spot 实例
- 资源标签与成本归因
- 闲置资源清理
- 存储分层（热 / 温 / 冷）
