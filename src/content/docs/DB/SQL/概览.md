# SQL 概览

> 关系型数据库是数据持久化的基石。本目录收 SQL 语言、关系型数据库设计、查询优化、事务与隔离级别相关内容。

## 知识地图

### 关系型数据库

- MySQL / PostgreSQL / SQLite / SQL Server
- 表设计范式（1NF / 2NF / 3NF / BCNF）
- 主键 / 外键 / 索引 / 约束

### SQL 基础

- DDL（CREATE / ALTER / DROP）
- DML（SELECT / INSERT / UPDATE / DELETE）
- DCL（GRANT / REVOKE）
- JOIN 类型（INNER / LEFT / RIGHT / FULL / CROSS）

### 索引与查询优化

- B-Tree / Hash / GIN / GiST
- 覆盖索引 / 联合索引 / 最左前缀
- EXPLAIN / Query Plan
- 慢查询分析

### 事务与并发

- ACID 特性
- 隔离级别（Read Uncommitted / Read Committed / Repeatable Read / Serializable）
- 锁机制（行锁 / 表锁 / 间隙锁）
- MVCC（多版本并发控制）

### 高级主题

- 视图 / 存储过程 / 触发器
- 分区表 / 分库分表
- 复制（主从 / 主主）
- 备份与恢复
