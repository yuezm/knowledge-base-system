# DevOps 概览

> DevOps = Development + Operations 的协作文化与工程实践。本目录收 CI/CD、容器、编排、监控、日志、IaC 等领域。

## 知识地图

### CI/CD

- 版本控制与分支策略（Git Flow / Trunk-Based）
- CI 工具（GitHub Actions / GitLab CI / Jenkins / CircleCI）
- CD 策略（蓝绿 / 金丝雀 / 灰度）
- 制品管理（Artifact / Container Registry）

### 容器与编排

- Docker 基础（镜像 / 容器 / Dockerfile / 多阶段构建）
- Docker Compose（多容器编排）
- Kubernetes（Pod / Service / Deployment / ConfigMap / Secret）
- Helm（K8s 包管理）
- Service Mesh（Istio / Linkerd）

### 基础设施即代码

- Terraform（多云 IaC）
- Ansible（配置管理）
- Pulumi（代码化 IaC）
- CloudFormation（AWS 专属）

### 监控与可观测性

- Metrics（Prometheus / VictoriaMetrics）
- Logs（ELK / Loki / Fluentd）
- Traces（Jaeger / OpenTelemetry / Tempo）
- 告警（Alertmanager / Grafana）

### 日志与调试

- 集中式日志架构
- 结构化日志（JSON / Logfmt）
- 链路追踪（Distributed Tracing）

### 部署模式

- 虚拟机 / 裸金属
- 容器化部署
- Serverless（Lambda / Cloud Functions）
- 边缘部署（CDN / Edge Functions）
