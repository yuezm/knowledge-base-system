### 可视化

一般可视化，可分为如下

1. 地理编码，将非空间化的数据转换为 GIS 坐标系（投影）
2. 可视化
   1. 绘制点
   2. 绘制线
   3. 绘制面
   4. 绘制栅格
3. 空间叠加，例如将不同的层级叠加
4. 计算，包含距离计算，面积计算，包含计算等等

## 专业名词

1. CRS（Coordinate Reference System）：坐标参考系统，用于描述坐标系
2. SRS（Spatial Reference System）：空间参考系统，用于描述坐标系
3. GCS（Geographic Coordinate System）：地理坐标系统，用于描述坐标系，直接用经纬度来定位球体上的点。通常为 WGS84，EPSG:4326
4. PCS（Projected Coordinate System）：投影坐标系统，用于描述坐标系，将地理坐标系统投影到平面上的坐标系。通常为 Web Mercator，EPSG:3857
5. EPSG（European Petroleum Survey Group）：欧洲石油调查集团，用于描述坐标系。例如 EPSG:3857 表示 Web Mercator，EPSG:4326 表示 WGS84
6. GeoJSON：一种 JSON 表示法，用于描述几何对象。是矢量数据
7. GeoPackage：一种数据库格式，用于存储几何对象
8. Shapefile：一种文件格式，用于存储几何对象
9. KML：一种文件格式，用于存储几何对象
10. GPX：一种文件格式，用于存储几何对象
11. WKT（Well-Known Text）：一种文本表示法，用于描述几何对象
12. WKB（Well-Known Binary）：一种二进制表示法，用于描述几何对象
