## 世界坐标系

Three.js 的世界坐标系是一个右手坐标系，原点在屏幕中心，

- X 轴向右
- Y 轴向上
- Z 垂直于屏幕轴向外。

## 屏幕坐标系

Three.js 的屏幕坐标系，原点在屏幕中心

- X 轴向右，值的范围，从左到右 -1 到 1
- Y 轴向下，值的范围，从上倒下 -1 到 1

和浏览器不同的是，浏览器的坐标系是，原点位于左上角

- X 轴向右值的范围，从左到右 0 到 width
- Y 轴向下，，从上到下 0 到 height
