## API

### box-shadow

```css
box-shadow: [inset] <offset-x> <offset-y> <blur-radius> <spread-radius> <color1>
  <color2> inset：内阴影 offset-x：x便宜，可为负 offset-y：y便宜，可为负
  blur-radius：模糊度，越大越模糊，最小位0
  spread-radius：阴影宽度，越大阴影越宽，负值导致阴影缩小;
```

### text-align

```css
/* left right start end justify */
text-align: justify; /* 除却最后一行文字，其余文字均匀分布 */
text-align-last: justify; /* 最后一行文字，其余文字均匀分布 */
```
