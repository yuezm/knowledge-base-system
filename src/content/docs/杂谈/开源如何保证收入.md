## 捐赠和赞助

1. 企业募捐
2. 个人募捐
   靠企业或者个人募捐，收入是无法保证稳定的，此种例子 github 比比皆是

## 商用协议

使用商业协议，针对个人用户免费，商业用户收费

## 为更多的功能付费

1. 区分社区版本（免费）和商业版本（收费），通过免费的版本来吸引用户，而通过收费版本来获取收入。
2. 提供 VIP 功能，付费用户可以获得更多的服务，例如技术支持，定制化开发，专属客服等等

此种方法的重点

1. 付费版本必须远远优于免费版本，例如 GPT4.0 对比 GPT3.5
2. 必须给予付费客户和免费客户不同的服务，体现出 VIP 的特权
3. 必须给予客户信心，
   a. 一定的包装，让客户觉得这个东西很高级
   b. 明确的计划和进度，让客户觉得这个东西是可靠的，客户提的功能是可预期的
   c. 足够的安全感，让客户觉得这个项目是可靠的，不会付费完就跑路
   d. 足够便捷的付费方式

## 托管

除去提供软件外，还提供一站式服务，例如提供托管服务，用户只需要支付托管费用，而不需要关心服务器，网络，部署等等
