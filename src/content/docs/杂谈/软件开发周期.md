---
title: 软件开发周期
description: 软件开发周期
---

软件开发周期一般如下

1. 确认目标
2. 需求调研
3. 需求分析（需求评审）
4. 设计

   1. 交互和 UI
   2. 技术文档（开发设计）

      1. 架构设计
      2. API 设计（前后端对接）
      3. 数据库设计
      4. ...

   3. 测试文档

5. 开发
6. 测试
7. 交付（上线）
8. 迭代

在做项目时，需要保证

1. 可使用（稳定性，性能，用户体验）
2. 可扩展
3. 可维护
