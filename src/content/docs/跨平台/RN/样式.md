## StyleSheet

```jsx
import { StyleSheet, Text, View } from 'react-native';

<Text style={ styles.container }></Text>

{/* rn中宽高都是和设备无关的逻辑像素 */}
<View style={{ height: 50, width: '50%' }}></Text>

{/* rn 默认为flex布局 */}
<View style={{ flex: 1 }}></Text>

{/* 样式表 */}
const styles = StyleSheet.create({
  container: {
    marginTop: 50,
  }
});
```
