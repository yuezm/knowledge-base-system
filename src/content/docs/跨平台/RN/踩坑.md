## 热更新导致 NativeModule 实例属性重置

```java
public class MavlinkBridgeModule extends ReactContextBaseJavaModule {
    private XX xx;
    private static XX staticXX;


    @ReactMethod
    public void connect() {
      this.xx = xx; // 此属性，在按 r 刷新时会消失
      staticXX = xx; // 此属性不会消失
    }
}
```
